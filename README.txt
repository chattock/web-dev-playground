WEB DEV PLAYGROUND
A hands-on page for every lecture of the Angela Yu Web Development Bootcamp
==============================================================================

TO START IT
-----------
Double-click  start.command

A terminal window opens and your browser goes to http://localhost:4173
Leave that terminal window open while you work. Close it (or press Ctrl+C)
to stop the server.

If double-clicking is blocked by macOS security, open Terminal, drag the
folder in, and run:   python3 server.py


WHAT IS IN IT
-------------
All 374 lectures, numbered as in the course, in the course's 45 sections.

  HTML, CSS, Bootstrap, JavaScript, DOM, jQuery   live preview + console
  React                                           compiled in the browser
  Node, Express, EJS, APIs, auth                  simulated server with a built-in
                                                  browser and a Postman panel
  SQL and PostgreSQL                              real Postgres in the browser
  Command line and git                            simulated shell and git
  Web3 / Motoko                                   code walkthroughs, React front ends
  Theory, tips, admin                             notes + quiz

Press / to search for a lecture by number or title.
Your edits and "done" ticks are saved in this browser.
